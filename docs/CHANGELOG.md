### Changed
- 本地 `.env`（gitignored，不入库）：`JWT_SECRET_KEY` 由占位值 `change-me`（9 字节）替换为 **64 字符强随机密钥**。原因：PyJWT 2.14 对 HS256 密钥长度 < 32 字节会抛 `InsecureKeyLengthWarning`（RFC 7518 §3.2），弱密钥可被离线暴力破解，直接威胁 Access Token 的签名有效性。（TASK-016）
