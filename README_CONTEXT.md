# TaskFlow Pro AI Coding Context

本目录是根据《团队任务协作系统项目开发文档》初始化的 AI Coding 上下文。

## 使用方式
将整个目录内容复制到 TaskFlow Pro 项目根目录：
- `docs/`：长期项目上下文
- `.cursor/rules/`：Cursor 自动规则
- `TASKS.md` 可由需要时放在根目录；当前任务清单位于 `docs/TASKS.md`

## 第一次开发
当前只允许执行：
`Phase 1 -> TASK-001`

完成一个 TASK 后必须真实验证，再更新 `PROGRESS.md` 和 `CHANGELOG.md`，然后等待下一步。

## 来源原则
原始项目开发文档中的明确内容视为需求；初始化过程中补充的内容只用于组织上下文，不应被当作新增业务需求。
